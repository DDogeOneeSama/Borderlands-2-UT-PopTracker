# Borderlands-2-UT-PopTracker
A [Universal Tracker](https://github.com/FarisTheAncient/Archipelago/releases?q=Tracker) map pack for Borderlands 2 with Archipelago Support.

Currently a major WIP with the BL2 Archipelago not even being complete yet.

# **THIS IS NOT FOR USE WITH POPTRACKER**
This is a tracker pack to be chosen when you are asked to select a pack on launch of the Borderlands 2 Client. This will not work with PopTracker, it simply uses the PopTracker specifications to make the tracker.

# Installation & Usage

1. Download the latest version of the Universal Tracker apworld. Install it by dragging it onto the Archipelago Launcher or moving it into your custom_games folder. Also have the apworld for Lego Harry Potter Years 5-7 installed.
2. Download the latest release of this pack on the [releases](https://github.com/DDogeOneeSama/Borderlands-2-UT-PopTracker/releases/latest) page (`.zip`)
3. Place the `.zip` into a folder of your choice. Do **not** extract it, as that will not be compatible with Universal Tracker.
4. Open Universal Tracker in the Archipelago Launcher and connect to your server and slot. The tracker should prompt you with a window to choose the pack file. Once selected, you can use the "Map" tab in the tracker to see the locations.
